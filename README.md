# Personal Expense Calculator

A simple browser-based tool to track monthly income and expenses.

## How to run
Unzip the folder and open `index.html` in any modern browser. No install or internet connection needed.

## Files
- `index.html` – page structure and form fields
- `style.css` – layout and styling (responsive)
- `script.js` – calculations, validation and live updates

## Features
- Inputs: monthly income, rent, food, transportation, utilities, shopping, entertainment, other
- Calculates total expenses, remaining balance and savings percentage automatically
- Updates instantly as you type
- Validation: rejects letters, negative numbers and oversized values with a message under the field
- Warns when spending exceeds income or savings are below 20%
- Visual breakdown of expenses as a share of income
- Currency selector (INR, USD, EUR, GBP) and a clear-all button
